What is computer programming?

Computer programming is the process of writing instructions that a computer can execute to perform tasks or solve problems. A programming language provides rules for expressing these instructions.

Python is a high-level programming language known for its readable syntax. It is used in web development, automation, data analysis, artificial intelligence, and education.

Important concepts

  • Algorithm: A step-by-step procedure for solving a problem.
  • Program: A set of instructions written for a computer.
  • Syntax: The rules for writing valid code.
  • Debugging: Finding and correcting errors in a program.
  • Programiz: An online platform that provides free compilers and code editors for various programming languages, making it easy to learn and practice coding.
  • Data Types: Different types of data that can be used in programming, such as integers, strings, and arrays.

Real-life example: Making a sandwich

An algorithm might tell you to prepare bread, add a filling, place the second slice on top, and serve. A computer program also follows instructions in a logical sequence.

Variables and data types

A variable is a named reference used to store a value in a program. In Python, you can create a variable by assigning a value to a name.

student_name = "Alex"
age = 17
grade = 92.5
is_enrolled = True

print(student_name)
print(age)
print(grade)
print(is_enrolled)

Common data types

Data typePurposeExample
strText"Hello"
intWhole numbers17
floatDecimal numbers92.5
boolTrue or false valuesTrue

Remember: text values need quotation marks. Variable names should be meaningful. Python is case-sensitive, so age and Age are different names.

Input and output

The input() function receives text from the user. The print() function displays information on screen.

name = input("Enter your name: ")
print("Welcome to Comprogramming,", name)

Sample output

Enter your name: Alex
Welcome to Comprogramming, Alex

The program asks for a name, stores the response in a variable, and then displays a greeting.

Performing calculations

first_number = int(input("First number: "))
second_number = int(input("Second number: "))

total = first_number + second_number
print("Sum:", total)

The int() function converts suitable text input into a whole number. Without conversion, input is normally returned as a string.

Conditional statements

Conditional statements allow a program to choose different actions depending on whether a condition is true or false.

score = 85

if score >= 75:
    print("Passed!")
else:
    print("Keep practicing!")

In this example, a score of 75 or higher displays "Passed!". Otherwise, the program displays "Keep practicing!". Python uses indentation to define the code inside each branch.
